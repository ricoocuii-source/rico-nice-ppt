# QA

打开网页看，不只看代码。

- [ ] 封面沉底，display 约 9.5vw，不是通栏自造封面
- [ ] 对比页两栏结构同质
- [ ] 没有 80px 网格
- [ ] 没有 WebGL / `#gl-bg`，纸面是实色 `--c-bg`，整本只有一种纸色
- [ ] 没有改 `--sz-*`
- [ ] `<em>` 是强调色，不是第二套标题样式
- [ ] chrome 和 kicker 不是同一句话
- [ ] 一页一件事，没有把信息卡密度塞进来
- [ ] 页码只由翻页引擎写在页眉右上角（`.chrome-page`，封面除外），markup 里没有手写页码。没有 `#slide-counter`，没有页脚，没有 `slide-foot`
- [ ] 标题折行后最后一行不少于 3 个汉字（或 3 个英文单词），没有「公 / 斤」这类拆词
- [ ] 没有 Image Placeholder、「报告页」空框、假手机、假聊天
- [ ] `python3 scripts/check_contrast.py` 全绿
- [ ] 没有 `[Period]` `[Organization]` 这类方括号占位，没有残留英文示例句
- [ ] 分割线看得见（`--c-hairline`），不是几乎融进纸里的一条
- [ ] kicker / caption / 坐标轴标签在投影上读得出来，不是灰得发虚
- [ ] 图表柱子、金字塔色带、甜甜圈扇区跟纸面分得开
- [ ] 每页内容撑满 16:9，没有上下各空三分之一的浮岛
- [ ] 说明文字紧跟它的标题，没有被甩到栏底
- [ ] 图标：一页只有一种槽位；大图标与左侧文字块同一水平线、颜色同标题；小图标只在并列项上且同组全有全无；没有残留空的 `data-icon` 元素
